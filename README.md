# 차세대 메타인지 테스트

20대 대상 모바일 에니어그램 기반 테스트 웹페이지입니다. 서버나 빌드 과정이 필요 없고, 한 번 접속한 기기에서는 인터넷 없이도 동작합니다.

## 구성

- 시작 → 기본 정보(이름, 성별, 태어난 연도) → 문항(10문항씩 9단계, 총 90문항) → 결과 → 9가지 유형
- 18세 이상만 참여 가능 (올해 연도 − 출생 연도 ≥ 18, 2026년 기준 2008년생까지)
- 점수: 1~5점, 유형별 9문항 합계(9~45점)
- 주 유형: 합계 최고점. 동점이면 번호가 빠른 유형
- 날개: 주 유형 양옆 번호 중 점수가 높은 쪽. 동점이면 번호가 빠른 쪽
- 결과 보기를 누르면 A4 가로 3쪽 PDF가 자동 다운로드됨 (1쪽 결과, 2쪽 문항별 점수, 3쪽 상담사 참고 문항)
- 응답은 어디에도 저장하지 않음. 결과는 참여자 기기에 받은 PDF로만 남음
- 결과 화면의 "처음으로"를 누르면 이름·응답이 지워지고 시작 화면으로 돌아감

## 배포

Netlify에서 이 저장소를 연결하면 자동으로 배포됩니다. 빌드 명령은 비워두고, 배포 폴더는 `/`(저장소 최상위)로 둡니다.

## 오프라인 사용

- 인터넷이 될 때 사이트에 한 번 접속하면 `sw.js`가 필요한 파일을 모두 기기에 저장합니다. 그다음부터는 인터넷이 없어도 열리고 PDF도 만들어집니다.
- 휴대폰에서는 브라우저 메뉴의 "홈 화면에 추가"로 앱처럼 쓸 수 있습니다.
- **사이트 파일을 고칠 때마다 `sw.js` 맨 위 `CACHE` 이름의 숫자를 하나 올려야** 이미 접속했던 기기에도 새 버전이 반영됩니다. (예: `meta-test-v1` → `meta-test-v2`)

## 파일 구성

- `index.html` — 테스트 화면 전체
- `sw.js` — 오프라인 저장
- `manifest.webmanifest`, `icons/` — 홈 화면 추가용 정보와 아이콘
- `vendor/` — PDF 생성 도구 (html2canvas 1.4.1, jsPDF 2.5.1, MIT 라이선스)
- `fonts/` — Black Han Sans, Noto Sans KR (SIL Open Font License). 테스트에 쓰인 글자와 자주 쓰는 한글 2,350자만 남겨 용량을 줄임
