# 차세대 메타인지 테스트

20대 대상 모바일 에니어그램 기반 테스트 웹페이지입니다. 파일 하나(`index.html`)로 동작하며, 서버나 빌드 과정이 필요 없습니다.

## 구성

- 시작 → 기본 정보(이름, 성별, 태어난 연도) → 문항(5문항씩 18단계, 총 90문항) → 결과 → 9가지 유형
- 18세 이상만 참여 가능 (올해 연도 − 출생 연도 ≥ 18, 2026년 기준 2008년생까지)
- 점수: 1~5점, 유형별 9문항 합계(9~45점)
- 주 유형: 합계 최고점. 동점이면 번호가 빠른 유형
- 날개: 주 유형 양옆 번호 중 점수가 높은 쪽. 동점이면 번호가 빠른 쪽
- 결과 보기를 누르면 A4 가로 3쪽 PDF가 자동 다운로드됨 (1쪽 결과, 2쪽 문항별 점수, 3쪽 상담사 참고 문항)
- 응답은 어디에도 저장하지 않음. 결과는 참여자 기기에 받은 PDF로만 남음

## 배포

Netlify에서 이 저장소를 연결하면 자동으로 배포됩니다. 빌드 명령은 비워두고, 배포 폴더는 `/`(저장소 최상위)로 둡니다.

## 사용 라이브러리

- html2canvas 1.4.1, jsPDF 2.5.1 (cdnjs에서 불러옴)
- 글꼴: Black Han Sans, Noto Sans KR (Google Fonts)
